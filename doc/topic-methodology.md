# AIGC 纪录片选题方法论（调研综合 + 管线对照）

> 2026-09-03 研究成文。来源：纪录片提案体系（CCDF / 新鲜提案·黎里）评审维度、爆款案例分析（人间世 / 舌尖上的中国）、2025 年 AIGC 纪录片行业实践、本项目测试集 `doc/topic-testset.md` 的适配度分层。
> 用途：选题管线（发散 → 收敛 → 深挖）的设计依据；回答「为什么这样发散、为什么这样收敛」。

## 一、专业体系怎么评选题：提案大会五维

CCDF（CNEX 华人纪录片提案大会）与「新鲜提案·黎里真实影像大会」（累计征集 1503 部、成片 59 部登陆平台）的评审维度高度一致：

| 维度 | 内涵 | 我们的对应 |
|---|---|---|
| 创意构想 | 原创性、艺术表达、角度是否新 | 发散层的方向多样性 |
| 选题价值 | 社会意义、时代性、独特性 | 题眼闸 + 公共情绪问 |
| 可行性 | 素材可得、制作落地、周期成本 | **AIGC 语境 = 素材基础问（射程判断）** |
| 市场潜力 | 平台采购、对标片表现 | 深挖层市场实查（已有） |
| 传播路径 | 节展、国际发行 | 暂不进生料层（导演阶段判断） |

## 二、爆款的底层规律

从《人间世》《舌尖上的中国》等案例的分析归纳，四条可操作的规律：

1. **切中公共议题**：人间世=医患与生死，舌尖=食物与家。选题的题眼必须连着一个大众都在经历的命题，而不是圈内人才关心的事。
2. **个体承载普世情感（以小见大）**：舌尖不以菜系为主线，用具体人物故事串联；人间世开篇即呈现「不治」的失败案例。切口是人，题眼是命题。
3. **精准共情公式**（人民网表述）：在「故事主角 × 纪录片主题 × 社会发展主线」三者之间建立逻辑关联——三环扣上才是选题，只有一环是素材。
4. **受众观先行**：为谁拍决定形态——B站偏深度影视级（DiDi_OK 科幻/悬疑/哲思半年 30 万粉），抖音偏大众情绪共鸣；历史+AI 是当前红利赛道（「睡前历史说」15 作品 26 万粉，AI 账号 2026 Q1 单季变现超 2025 全年）。

**真实性在 AIGC 语境的转译**：行业共识底线是「技术是补足证据缺口的手段，而非虚构历史的工具」（2025 光明网年度盘点）——AIGC 不降低选题的真实标准，只改变画面获得方式。

## 三、AIGC 纪录片的特殊约束：素材基础决定射程

2025 年 AIGC 纪录片的成熟案例**全部**是历史/文化遗产/档案方向：《中华五千年》（优酷，AI 学古代绘画/壁画/青铜器纹饰做场景重现）、《长征·江河纪》（北京台 AIGC 全流程）、《英雄无名》《帛书传奇》（历史场景复原）、《圆明园·重生》（AI 重现园林）。

**射程判断的唯一问题：这个选题的画面从哪里来？**

- **射程内**（档案/文物/历史场景/地理航拍/物件/数据可视化可 AI 生成）：历史考古、大案档案型罪案、军事档案修复、科技科普、财经商业史、美食影像、自然风格化科普、儿童科普动画、旅行地理航拍（详见 `doc/topic-testset.md` 十五节分层）
- **射程外**（核心价值依赖真实实拍，砍）：警务/医院/庭审真人跟拍（守护解放西式）、素人长期跟踪（人生第一次式）、真实调查报道（制造杀人犯式）、真实赛事授权、现场演出档案

**推论：传统选题方法论里的「人物要可跟拍」在 AIGC 语境下要反转为「人物要可呈现」**——历史人物/档案人物/群像可考据还原即可；需要现实跟拍活人的选题反而是弱项，除非转成档案+再现混合形态。

## 四、发散方法论：从一条线索到一个选题空间

三条开掘路径（先发散再收敛的发散纪律）：

1. **横向六轴**（已有）：人物 / 制度 / 工艺 / 地点 / 时代 / 关联——线索直接牵着的人和事。
2. **纵向升维**（已有）：线索是哪个全国现象的缩影、哪个行业的一角、哪个时代的切片、哪类人群的命运样本。切口可以小，题眼必须大。
3. **策划惯用轴**（本次补）：
   - **对标改编轴**：海外/历史上已验证的爆款模式，中国化/本地化（策划最常用捷径——《守护解放西》即 COPS 模式本地化）
   - **反差极端轴**：最后一代 / 唯一存活 / 最老 / 最快 / 最大——极端性自带悬念
   - **组合轴**：A 题材 × B 题材交叉出新带（历史×美食=风味人间，地理×工程=超级工程）

## 五、收敛方法论：AIGC 选题五问

三问升级为五问（新增两条加粗）：

1. **题眼与体量**：承载的是一类人群的命运 / 一个行业的兴衰 / 一个时代的切片 / 一种文明现象？单人物单事件除非情境极端或浓度极高，要么升维要么砍。
2. **素材基础（AIGC 射程）**：画面从哪来——档案、文物、历史场景、地理、物件、数据可视化是否可得可生成？依赖真人实拍跟拍采访的砍掉或转档案型。
3. **人物可呈现性**：人物是可考据还原的历史/档案人物或群像，还是必须现实跟拍的活人？
4. **纵深**：时间、空间或人群上的跨度。
5. **公共情绪**：题眼连着普遍人性命题（生死/亲情/公平/好奇）或当下时代情绪（老龄化/返乡/AI 焦虑）吗？观众看完会讨论转发吗？

五问全过才成卡。arc 记录为四段式：**「题眼：…；素材：画面从哪来；跟拍/呈现：谁；弧线：从哪到哪」**。

## 六、管线对照

| 方法论 | 管线落点 | 状态 |
|---|---|---|
| 横向六轴 + 纵向升维 | 发散 flow 提示词 | ✅ |
| 对标改编 / 反差极端 / 组合交叉轴 | 发散 flow 提示词 | ✅ |
| 题眼与体量问 | 收敛五问之一 + 代码闸 '题眼' in arc[:12] | ✅ |
| 素材基础（AIGC 射程）问 | 收敛五问之二 + arc 素材段 + 代码闸 '素材' in arc | ✅ |
| 人物可呈现性问（可考据还原 ≠ 可跟拍） | 收敛五问之三；verdict 的 person_anchor 措辞反转 | ✅ |
| 纵深 / 公共情绪问 | 收敛五问之四、五 | ✅ |
| arc 四段式（题眼/素材/呈现/弧线） | 收敛输出 + 落库字段 + 前端详情展示 | ✅ |
| 形态意识（AIGC 形态 / 叙事形态） | 收敛 tags 形态词（档案再现/CG科普/地理航拍/数据可视化/文物活化/风格化动画；系列网格/单片/单元） | ✅ |
| 可行性取证 | 深挖 research-plan：素材可得性查询优先（档案/文物/遗址/馆藏机构）+ 对标片查询；载荷带 arc 对着主张取证 | ✅ |
| 结论核实 | verdict：arc 核实纪律（题眼撑不住进 gaps、素材入口查到进 material_base）；material_base 限 AIGC 射程内 | ✅ |
| arc 贯通 | `TriagePick.arc` → plan/verdict 载荷（深挖知道生料卡的主张才能核实它） | ✅ |
| 市场潜力（对标/同题密度） | 深挖 market_probe 实查 + competition_gap 引用计数 | ✅（原有） |
| 传播路径（节展/国际） | 导演阶段判断，不进生料层 | — |
| 受众观（B站深度/抖音情绪） | 导演阶段判断；raw 层不预设平台 | — |
