# 自由生图（生图台）

**一句话定位**：不读项目画风、不注入版式契约、不写画布、不进资产库的**自由创作出图**——与画布出图完全隔离的两条线。

## 什么时候用哪条（先分流，别用错工具）

| 用户要什么 | 走哪条 | 工具 |
|---|---|---|
| 画布上某张资产图/分镜图/图片卡要**出图·重出·改图** | 画布卡出图链 | **`regenerate_card_image`**（+ `read_skill("revise-assets")` 分层） |
| 资产卡/分镜的**设定图/剧照**批量出图 | 画布卡出图链 | `generate_asset_images` |
| **不带画布语义**的自由创作（试提示词、多模型对比、概念探索） | 生图台 | **`generate_free_image`** |
| 上传的图（海报底图/运营底图）要当参考出新图 | 生图台 | `generate_free_image` 带 `reference_images_json` |

**判据**：这次出图是要**落到某张画布卡上**（改它的画面），还是要**产生一张新图**？前者走画布卡链（要画风闸、版式契约、参考职责、版本档案），后者走生图台（原话直传、无画风、产物在画廊）。

## 生图台的关键语义

- **提示词逐字直传（KEEP 语义）**：不扩写、不套版式、不注入项目画风。用户说什么发什么——用户要的是"这句话画出来什么样"，改写它就毁了这次实验。要扩写是画布卡链的事（那边有「AI 扩写」）。
- **一次点击可多模型并行**（`models_json` 传多个 = 同题各出一张对比）；**画幅/档位取决于所选模型的支持集**，空交集要明报并让用户减少模型，不要静默换档。
- **参考图**：`reference_images_json` 传 URL 数组（画布图卡的 imageUrl 或 `/agent-service/assets/` 链接），按顺序为 图1/图2…；提示词里可用「`@图1 锁定脸部`」这类注解指定某张参考的用法（注解会被抽出来并入「参考图编号」行）。参考张数上限 = 所选模型的最小 `max_references`。
- **产物落在生图画廊**（生图页右侧、约 30-90 秒），**不写画布、不进资产库**——所以它天然不是"改图"，改图不能被它替代。

## 结果送上画布

用户想把生图结果变成画布卡时（`list_free_images` 拿 `imageUrl` → `canvas_ops add_node` 建图片卡），**明确告知这是一张新图卡**：它不是对某张已有卡的修改，也不会继承那张卡的设定/画风/版本档案。如果用户的真实意图是"改原来那张"，回到 `regenerate_card_image`。

## 边界（不要越界）

- **不用它出设定图/分镜图**：那两类要画风闸、版式契约（四格定妆/三视图/剧照语义）与资产一致性参考——生图台全都没有，出来的图落不进资产链。
- **不要为它编造画幅**：不传就是模型默认；用户点名画幅才传，传了先确认在该模型支持集内（不支持是整批 400，不是单张）。
- **不要把画风塞进提示词**：想让自由出图也统一质感，正确做法是让用户先定项目画风再走画布卡链，而不是把画风句抄进 prompt。
