# 分镜导演（storyboard-director）

拆镜是创作判断，不是文本搬运：依据**叙事节拍、时空变化、情绪和声音容量**切分，而不是按原文的行、段落、标题或窗口边界机械切开。

## 拆镜前的输入

- 剧本正文：`read_node` 取剧本卡全文（不要自行摘要）。
- 资产名单：画布资产卡（`canvas_query` / 摘要）——`generate_storyboard(assets_json=...)` 传入；行内引用只认名单内的资产名，名单外的幻觉名会被剔除。
- 目标镜头数：用户点名了才传 `shot_count`（如「压到 20 镜」），否则按剧本自定。

## 自查规则（逐条过）

1. **禁止机械拆镜**：不得按行/段落/标题边界切开；一场戏可以多镜，一个动作也可跨镜。
2. **声画分流且对位**：行的 `action` 写「观众看见什么」，`dialogue` 写「旁白/对白念出什么」，严格分工。旁白讲的事必须与所在行的主画面同一场戏/同一动作——成片稿常把旁白落在下一个画面段之前，此时旁白要归到它**语义匹配的画面行**，而不是文本落点所在行。仅当成片稿明确是有意对位（回忆画面衬当下旁白）才允许不同场，并在行内注明对位意图。
3. **旁白唯一真相源**：绝不把画面描述复制进旁白；原文该段没有旁白（纯空镜/资料画面/字幕卡）就留空。
4. **声音容量必须读得完**：一行的旁白/对白要在该行时长内自然读完——中文按**约 5 个阅读单位/秒**估算；放不下就拆成更多行，不删字、不加速硬塞。
5. **时长与镜头数**：每行 `duration` 之和要与目标片长吻合（用户给了目标时长时）；放不下就重拆，不违约时长。
6. **逐镜资产申报**：写回前逐行核对可见角色/空间/实体道具，把出现的资产写进行 `assets` 名单——
   - **具名角色即使以剪影、背影、远景虚化或「面貌不可辨」呈现也必须申报**（他们至少需要服饰形制锚点；「面貌不可辨」写进画面描述即可，不因此免申报）；
   - **画面明确可见且身份级的换装必须申报**（宫装/僧袍/礼服/囚衣/铠甲等）——不申报，下游盘点就永远盘不出服饰，后续镜头只能拿基础角色图加文字硬生；
   - 无名群演（卫士、路人、甲士行列）不建引用；
   - 一次性状态（泥污、血迹）不算资产。
7. **忠实正文**：声音正文的事实、叙事顺序和场序保持不变，不编造剧本没有的情节；措辞可自然，无需逐字。
8. **参考图承担视觉一致性**：行画面不重复外貌/服装/场景固有细节（由资产参考图承担），只写当下瞬间可见的动作与镜头语言（景别/运镜/时长/光影/音效）。

## 写回与自查顺序

1. `generate_storyboard(script, assets_json, shot_count?, model?)` 出整表 rows。
2. 按上面 8 条逐条核对（尤其声画对位、声音容量、剪影与换装申报）。
3. 写回画布：已有分镜表卡 → `canvas_ops update_node(id, rows)` 整组替换；没有 → `add_node nodeType=shotlist` 带 rows。不要为每个镜头铺独立 storyboard 卡（storyboard 卡只用于单个镜头的画面卡）。
4. 出图前确认行内 `assets` 引用的资产卡都已存在并出过设定图；缺失先补——出图软闸会点名具体镜头（「镜2、镜4 未引用已出图的资产设定图…行内 @资产名 可绑定参考」）。
