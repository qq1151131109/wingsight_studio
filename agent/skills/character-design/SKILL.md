# 角色造型设计（命题先行）

造型设计先出**命题**，再出图。直接拿拆资产的外观描述去出图，出来的是「平均脸」——
多个角色撞形状、撞色、并排分不清。本手册在「拆资产之后、出正式角色图之前」补一道
造型设计工序：对着**全组**角色想清每个人的图形语言，呈用户确认后再出图。

角色**一致性**（同一角色跨镜头、多次出图长一样）不归本手册——那靠参考图与外观 DNA
内联，见 asset-aware-generation。本手册管的是**造型质量与角色间的区分度**。

## 职责分界

| 环节 | 负责 | 不做 |
|------|------|------|
| 考据（research_asset_references） | 圈「不能改什么」：史实、肖像、冠服形制、器物 | 不决定这部片怎么画这个人 |
| 造型设计（本手册） | 对全组出命题，呈用户改，确认后落卡 | 不写生图提示词、不编细节纹样 |
| 出图（generate_asset_images） | 按已确认命题 + asset-aware-generation 出图 | 不改造型命题 |

把史料/剧本写成五官清单是执行，不是设计；设计交的是**造型简报**，不是提示词。

## 何时进入

- 一批角色即将出正式设定图（character 资产卡要出图），而画布上还没有覆盖这些角色的造型简报。
- 已有设定图的角色（资产卡 imageUrl 非空、或用户采纳的成品图）是**锚点**，不重走设计——但要读进 lineup 当参照。
- 单角色补出、换装（Look 造型图）不必走全组设计；新角色加入已有全组时，要对照 lineup 想反差。

## 设计方法：先看全组，再看单人

一部片里所有未定型的角色**一次做完**，对着整组已锁定形象来想——不是给某个角色单独写一段衣服。

### 第一步：收集锚点与约束
- 已锁定形象：imageUrl 非空的角色卡，读其形象与图（占了什么形状、什么色，别人不能再碰）。
- 考据约束：research_asset_references 产出的 researchBrief 里「不能改什么」。
- 角色设定：拆资产产出的 description/visual_notes、性格、关系、戏剧功能（read_node 读角色卡全文）。

### 第二步：建 lineup 色板表
造型简报里维护一张全组表：每个角色占的**形状母题、主色块、体型量级、高度档位**。
新角色只负责和已有角色形成**反差**——并排要一眼分开。A 已占橙绿蓝，B 就不能再做圆润米色。

### 第三步：每个未定角色只回答四件事
1. **图形一句**：这个人在画里是什么形。戏剧功能必须变成图形——体积、棱角、色压，不写性格形容词。「家里的雷区」→「方正、占地大、全组最硬的冷色块」，不是「温柔微胖主妇」。
2. **剪影**：缩成黑影还认得出。认不出就还没设计完。
3. **两三个专属色块**：全组里只属于他，从 lineup 表挑没被占的位。
4. **禁止类件**：写明不是什么（不是商业动画保姆妈模板、不是高傲白猫模板）——设计层的否定，防出图落入类型平均脸。

### 第四步：呈用户，改命题
用户认的是造型简报，不是一堆生成图。整组一次呈报（lineup 并排），让用户改命题/剪影/色块
（改的是简报文字，不是重新出图比较）。用户确认后再出图。

## 产物：造型简报落画布

用 canvas_ops 建一张 note 卡（标题「造型简报」），正文含全组 lineup 表 + 每个角色的四件事：

```markdown
## 全组 lineup
| 角色 | 状态 | 形状母题 | 主色块 | 体型量级 | 高度档位 |
|------|------|---------|--------|---------|---------|
| 关关 | 锁定锚点 | 圆+锐角细节 | 橙/绿/蓝 | 小 | 1.5m 档 |
| 妈妈 | 待设计 | 方正、占地大 | 全组最硬冷色 | 中大 | 成人档 |

## 妈妈
- 戏剧功能：家里的雷区与秩序压力。
- 图形一句：方正、占地大、最硬冷色块——圆角方形的秩序感。
- 剪影：方肩围裙轮廓 + 一丝不苟低发髻；与关关乱碎发轮廓并排一眼分开。
- 专属色块：藏青围裙 / 灰白上衣 / 一点警示黄。
- 禁止类件：不是保姆妈模板（圆润米色碎花 + 温柔圆脸）。
- 考据约束：（真实人物才有）史料锁定部分列明。
```

用户确认后：把每个角色的**造型命题**（图形一句 / 剪影 / 专属色块，禁止类件翻成正向枚举）
写进对应 character 资产卡的设定正文（出图自动带上，见 asset-aware-generation），并把造型
简报卡 connect_nodes 连到各角色卡。之后再出正式角色图。

## 硬边界

- 不写画风、媒介、渲染方式——画风归全局「画风」（底部坞），见 asset-aware-generation 画风闸。
- 禁止类件是设计层语言，不直接进生图提示词；写进资产卡设定时翻成正向描述（「利落方正的围裙廓形」而非「不要圆润碎花」）。
- 造型简报是创作真相：只经用户确认流转，不为赶出图跳过命题。
- 角色本体比例事实（头身比、身高差、短粗四肢）属于命题，可进简报。
