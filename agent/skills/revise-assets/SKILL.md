# 改图（分层路由）

用户要改一张已生成的图时，**先判断改的是哪一层**，再动手——改错层会白花额度还改不到位：
改设定重出会连脸一起变（用户往往只要改一个细节），只改画面又治不了设定本身错了。

## 通道表

| 用户的意思 | 通道 | 我们的做法 |
|---|---|---|
| 设定本身不对（「不像同一个人」「这个年代没有这种东西」「设定该是武将不是文官」） | **A 改设定 → 重出主图** | 改资产卡/图片卡的**设定正文**（`update_node` body），再调 `regenerate_card_image` 重出该卡（设定是出图自动注入的源头） |
| 只改穿戴/多一套造型（「换成囚衣」「加件披风」，脸和身份不变） | **B 走造型（Look）** | 建/改 Look 卡（独立图片卡，命名「资产名·造型名」）并连回资产卡；分镜行内 `@造型名` 指定用它 |
| 只动这张画面的某处（「把帽子改成斗笠」「去掉桌上的杯子」「背景换雨夜」「其他不变」） | **C 小步改图（默认优先）** | 调 **`regenerate_card_image`**（卡上出图/改图工具，与卡片输入条同一条管线）：prompt 只写要改的那处，改图语义自动保留其余部分、旧图入版本档案；**无谱系的有图卡（上传图）自动派生新卡**、原图不动。用户自己在卡上时，也可以让他用输入条的「改图」/「派生新卡」——两条路等价 |
| 改这镜的画面语言（机位/景别/光影/时长） | **D 改行或提示词 → 重跑该镜** | 改分镜行字段（`update_node` 的 `row`）或该镜的 `genPrompt`，再重跑该行出图 |
| 提示词本身错了（「别写'空荡的街道'」「照我这句话原样画」） | **E 改实际提示词 → 原样重跑** | 「节点信息」弹窗的**「实际发送提示词」**块：可编辑 → **「按此提示词重跑」**（整体替换渲染，跳过版式契约） |

**默认优先级（关键）**：拿不准时走 **C**——先出小步变体让用户看效果，满意后再回头发起 A（改设定重跑主图）。反过来先改设定重出，用户看到的是「我就想改个帽子，你把脸也换了」。

**改完必须自检**：`regenerate_card_image` 返回里带结果与成败——成功要看到新图 URL 才敢说改好了；返回失败就按 generation-recovery 处置，不要把「已提交」当「已改好」。

## 通道选择前先读

- `read_node` 读现有正文与 `genPrompt`——不知道当前设定与提示词就改，等于重写（宪法「改前先读」）。
- 有谱系（`genShot`/`genPrompt` 非空）的卡走本卡原位覆盖 + 版本档案；**无谱系的有图卡（上传图/素材库图）走派生新卡**，不要在源图上覆盖——系统已按此分流，你不要手改源卡图。
- 角色有 Look 图时先确认该用哪套：近景镜头穿错衣服一眼看得出，行内没写造型词就用定妆照（出图前会点名提示）。

## 硬规则

1. **一次只改 1-2 个变量**。用户一口气列 5 条时，先做前 1-2 条并说明余下分批——一次全改，出问题分不清是哪个变量造成的。
2. **「其他不变」要写进提示词**。C 通道的改图模板自带保留语义（只改指定处、其余不变）；走 A/D 通道时要自己把保留项写全（「除斗笠外，服装、姿态、光线与背景保持不变」），否则模型会顺手重画整张。
3. **主锚点 = 第一张参考**。改图时参考序列里必须含**原图**（本卡原图 chip 开着）；多说「参考图1」时指的就是它。
4. **失败迭代锚原图，不在错误版上连刷**。一次改不成就回到原图（版本历史「恢复此版本」）再改，别在前一版错误结果上继续叠加——错误会累积。
5. **改后必须重跑**。改了 `genPrompt`/行 prompt/设定之后，紧接着重跑对应产物（出图/出视频），不要留下「新提示词 + 旧画面」；被画风闸挡住就先处理闸门或明说待办。
6. **版本档案是回滚而不是备份**：重生成/改图/裁剪前的结果自动入档；「恢复此版本」= 当前版入档 + `genPrompt` 一并回滚。用户说「还是上一版好」就用它。
7. **设定改了要同步**：设定正文是出图注入的源头，改它之前先想清楚是不是所有该卡产图都该跟着变——只想改一镜就别动设定，走 C/D。
8. **失败处置**走 generation-recovery 手册（四选一决策树），不要在这里另立一套。

## 与相邻手册的分界

- 造型质量（多角色撞形撞色、类型平均脸）→ `character-design`（命题先行），本手册只管**改**。
- 一致性参考怎么选、画风闸、版式契约 → `asset-aware-generation`。
- 剧本正文的修改路由（定点小改/整稿重写）→ `real-documentary` 的「修改路由」节，那是**文字**的分层，与本节（**画面**）不同。
