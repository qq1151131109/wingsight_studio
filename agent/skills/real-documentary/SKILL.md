# 真实题材纪录片（real-documentary）

真实题材的总原则：**事实铁硬、呈现自由、推断克制**。事实边界来自实际取得并核对的材料；场面、节奏、气氛、概括性台词和象征表达可以创作，但不能改写会改变观众理解的关键事实。

## 入口：主题导览对话（先共享理解，再定方向）

导演抛来的往往是一个题材词（「我想做一部关于滇缅公路的历史纪录片」），不是创作意图——他对这个题材可能还没有系统认知，也还没被问过「为什么想做这个」。**题材词不等于授权进入策划/研究/候选生成**：读本手册只说明它可能适合当前领域，不说明可以开工。

先分流委托类型，再决定动不动手：

- **目标陈述**（只表达想做什么，没有具体对象、材料或角度）→ 走下面的导览对话，先对齐意图，**不出方向清单、不铺卡**。
- **探索委托**（点名要方向清单、让推荐、从零找题）→ 不走导览，按下方「候选全集先行」给真正不同的候选（核实与选项写法按宪法决策原则 3）。
- **执行委托**（已给题目、材料或已确认方向）→ 直接按任务推进，只有关键未知会显著改变结果时才停下对齐。

导览对话：

1. **先盘再讲**：做一轮轻量题材盘点（`web_search` / `web_fetch` 在对话里直接查，不发起深度调研、不建来源卡），摸清哪些单元有据、哪些是传闻、前人做过什么、留下什么空白。
2. **讲述而非答题（地图式完备）**：把题材的家底讲给导演听——**骨架必须列全**：题材共分几块就列几块，每块一行定位，数量诚实（拿不准就说「我盘到 N 块，可能还有」）；高光与反差、争议、空白按题材取用，不凑固定清单。每处标注材料底数：有据 / 须标注来源层次的传闻 / 前人已做满。**「哪块最值得做」的重点推荐等锚点到手后再给**（见下条），不夹带在地图里。创作标尺（观众、形态、单片还是系列、对标、必用材料）在对话中自然带出，不另设问卷。
3. **锚点与收敛**：讲述的同一轮把锚点问出口——参照作品（喜欢的片子/播客/账号都算）、动机（为什么是这个题材）、必放案例，任一到手即算；锚点未到手前方向判断只算临时、不落卡，每条消息只问一个问题。导演的回答常直接收敛出方向，当场确认理解后进入下面的执行流程；导演收窄方向时用一句陈述接住（「所以你要的是 X 这条线」）再继续讲。只有导演点名要选项、或他的方向与盘点结果冲突时，才把方向比较整理成 2-3 个实质不同的选项（各附一条盘到的最强材料）呈给导演拍板；其余情况继续用对话收敛。
4. **详略随人，节奏随导演**：导演显露行家认知就从简、直进争议与空白；明确要快（「别聊了直接写」）就压缩导览直接进策划。导览内容不落盘、不建第二真相，发现最终只进正式产物正文。

**候选全集先行**（与宪法共创契约同源）：盘点、筛选、挑案例这类请求（「有哪些能讲」「给我一批候选」「从这些里挑几集」）——先把符合条件的东西**列全**（数量诚实：有几个给几个；拿不齐就明说「我只查到 N 个，可能还有，要不要我再挖一轮」），每条给一句背景 + 材料底数（厚/中/薄）+ 来源；**再**给推荐（3-5 个，每个一句为什么）与被放弃者的原因——推荐与取舍**当场给，不等锚点**（「锚点到手后再推荐」只管上面目标陈述路径的导览讲述，不适用本条）。不要把长名单先替导演筛成短名单再让他选——「只有这 N 个吗」的追问就是这条缺口在报警。

导览对话不是新增确认点：它的出口就是方向共识，达成后直接进入下方执行流程。

## 意图路由：不是必经流水线

创作产物（整部策划、单集策划、资料核查、成片稿、分镜初稿）按**导演意图**路由——导演提到要策划就做策划，想先看到文字就直接起稿；上游产物存在则作为输入，缺失不阻塞。默认路径（导演没有别的指示时）：单集策划拍板 → 资料核查 → 成片稿 → 分镜。

- **对话起稿**：导演说「先写一版我看看」「按我说的写」→ 直接写稿（画布建剧本卡），凭导演已表达的意图整稿直出；方向仍是空白时先闪一次锚点问题（一问即止，拿到参照或动机就动笔）。没有研究输入时按「不虚构可核实史实、存疑处留【待核实】」写。回复里必须说明本稿有没有经过研究；导演满意后再以稿为底补策划/资料升级为研究稿。
- **完整研究链**：系列项目或导演要整部策划的正片，在默认路径之前加整部策划（含可拍单元盘点与选集表）。
- **剧本已给**（用户上传成品剧本）：剧本即成片稿，不跑资料核查、不重写——直接落剧本卡进入拆解/分镜链；只有用户明确要求改编/润色时才回到创作链。

## 重决策点与授权契约

创作段只有三个重决策点：**单集策划（讲法/呈现策略/承重事实取舍）、成片稿定稿、核心命题变更**。其中呈现策略默认拍脸、不主动列为选项（口径见「呈现策略门」），真正要呈报拍板的是讲法与承重事实取舍。其余产物写好后给出所在卡片即继续推进，不停等确认。

- **批准即授权包**：用户确认单集策划后，一路完成整稿成片稿，中途不再请求确认——用户随时发消息可打断或调整；打断与事后修订的成本，低于事前逐段审批中间产物的成本。中间产物是后续步骤的输入，不是用户审批对象。
- **先共享理解，后请求决策**：选项与确认请求不凭空呈现——先把形成选项所依赖的关键发现用对话讲给用户听（题材的家底地图、什么有据、什么是传闻、前人留下什么空白），让用户在理解材料的基础上判断，而不是对不了解的东西盲选。讲述详略按用户的认知与节奏调节（行家从简、直进争议；要快就压缩）。讲述中的发现只进正式产物，不落第二真相。
- 材料不足的决策不上用户（假确认）；材料足够的决策必须给足选项与实样（讲法 2-3 选，每选附同一场戏的 30 秒试写）。

## 修改路由

- **定点小改**（错别字、标点、格式，或用户明确指出的单句字面替换）：直接改剧本卡正文。必须同时满足：只改用户明确指出的文字、不发挥；单次只动一个连续片段且不跨场；不改数字/身份/因果/引语等事实；不显著增减字数。改后自检是否影响他场指代或因果，有连带就升级为整稿修订。
- **文句/场面/转场/节奏/开场结尾/整体连贯**：整稿重写或按场修订。把用户意见整理成「修改要求」（要达到的效果、必须改变、必须保留、不得越过的事实边界）＋「对话上下文」（用户原话里的审美偏好、明确否决过的方向、已达成的共识）——不代写新句子或场序，不加入用户没表达的审美判断。
- **事实/引语/具体动作问题**：回到资料核查（调研卡/卷宗）只更新受影响材料，保留证据边界，再改受影响场。
- **核心命题/主线/承载者/讲法/呈现策略变化**：回到单集策划修订，经用户重新确认后整稿重写，让新方向沉淀供后续集延续；局部腔调微调不必回策划，直接改稿。
- 用户要求整体润色或检查连贯性时，仍由同一个你整稿自我编辑，不创建审稿角色或自动修改循环。

## 呈现策略门

人物呈现默认**拍脸**（无肖像者考据推断脸 + 片尾统一标注）；只有导演明确表达剪影美学偏好或容貌有重大争议时才列为选项。**呈现策略一经选定即写进单集策划，成片稿画面描述必须遵循**——选剪影才用剪影语言，选推断脸不得写「不拍脸」。

## 考证大纲（资产考据的单位是时代，不是资产）

给资产做出图考据时，先切「考证大纲」，不要一个资产一次调研地铺开。

考据需求天然重叠，重叠分三类——**影响面最大的那类旧流程里没人做**：

| 类型 | 例 | 影响面 | 谁做 |
| --- | --- | --- | --- |
| 时代共有事实 | 服制基本形制、发式、宫室木构、器物形制 | 几乎全部资产 | **无主——靠大纲给它安一个主** |
| 跨资产共享的具体物 | 同一件朝服出现在 3 张卡上 | 2-5 张 | 收成一个主题，只查一次 |
| 单体专属 | 某角色本人的相貌与年龄感 | 1 张 | 不进大纲，参考图调研按资产走即可 |

按资产各搜一遍的代价不只是浪费：同一时代被各搜各的会得出互相矛盾的两套说法，
出图时在画面上打架（角色卡说北魏雄浑简朴、服饰卡出成明制凤冠）。**一个时代只该有一个
说法，由主题考据统一供给**——主题事实自动分发给它服务的每一张卡。

流程三步：`get_research_material` 看现状（已有条目 + 尚无考据的资产）→
`propose_research_outline` 切主题（整份替换）→ 讲给导演听、确认后
`run_research_outline` 执行。执行在服务端跑，状态写在大纲卡上，关页面也继续。

判据：

- **已有条目内容重叠**的一组卡 → 收成一个主题（它们的事实本来就是一套）。
- **没有任何卡认领的时代共有事实** → 单独成主题。别因为「没有卡提到它」就跳过——
  这类恰恰影响面最大、也最容易漏。
- **只影响一张卡且无时代共性** → 不进大纲。
- 主题的「服务哪些卡」是优先级依据：按服务卡数排，不要按资产顺序一个个来
  （影响 6 张卡的服制和影响 1 张的漆器不该花一样的时间）。
- 资产本尊涉及真实朝代（人物/地点/制度/服饰/器物）就要考据，哪怕整片虚构；
  纯虚构资产不必（与 asset-aware-generation 同一口径）。
- 年代能从题材或剧本确定时，用 `set_project_era` 记下时代口径——考据条目按它归档，
  同题材项目自动复用（同时代同主题不必重搜，界面上会标「复用自《X》」）。
  架空/穿越不要设。

产物两张卡，内容不重复：**大纲卡**＝计划与进度板（主题 / 服务范围 / 检索词 / 执行状态，
工具条有「执行主题」）；**考证报告卡**＝事实（逐主题与逐资产的考据事实、来源底账、
参考图底账、待补清单）。

## 阶段与产物（wingsight 载体）

| 阶段 | 产物 | 载体 | 用户决策 |
| --- | --- | --- | --- |
| 整部策划 | 创作方向 / 可拍地图 / 选集表（每集材料底数厚中薄） | note 卡《片名·整部策划》 | 系列项目确认方向；单片给卡即继续 |
| 单集策划 | 观看问题 / 发动机 / 竞争性解释 / 主动舍弃 / 事实边界 / 语言与开场方向 / 呈现策略 | note 卡《第N集·单集策划》 | **重决策**：讲法 2-3 选（附 30 秒试写）、承重事实取舍；呈现策略默认拍脸，仅导演表达剪影偏好或容貌有争议时列为选项 |
| 资料核查 | 来源底账 + 材料簇 | 调研卡（researchId）或 note 资料卡 | 无（事实问题走修改路由） |
| 考证大纲 | 主题（检索词 + 服务哪些卡 + 优先级） | note 卡《片名·考证大纲》（reportKind=ref-outline） | 确认主题与优先级后执行；产物见考证报告卡 |
| 成片稿 | 整集声画稿 | 剧本卡（每集一张，episodeNo） | **重决策**：通过 / 指场改 / 重写 |
| 分镜初稿 | Markdown 分镜表 | note 卡或分镜表卡 | 无（创作预览，可读可改可跳过） |
| 正式分镜 | 分镜表 rows | 分镜表卡（generate_storyboard） | 按 storyboard-director 手册自查 |

产物字段速释：**观看问题**＝这一集要带观众弄明白的一件事；**发动机**＝撑起整集的核心张力或机制；**竞争性解释**＝成片要主动压过的另一种流行讲法；**主动舍弃**＝明确不做、写出来防跑偏的东西；**语言与开场方向**＝旁白笔感、节奏与开场策略的定调。

## 在 wingsight 中的硬适配

- 没有文件工作区、没有 subagent、没有生产协调器：一切产物落在画布卡上（见上表）；改稿都改卡（`read_node` → 改 → `canvas_ops update_node`），聊天只给摘要与指向。
- 策划阶段的事实用 `web_search` / `web_fetch` 自己在对话里核实（顺手查证不算调研）；系统性取证才发起 `start_deep_research`（卷宗 = 资料包的等价物，引用保留 S 编号，争议双版本呈现）。
- 成片稿直接写进剧本卡正文（`canvas_ops add_node/update_node` 的 body；卡片工具条的「撰写」是用户侧入口）；没有「写作锁/原子发布」概念，改稿即改卡。
- 分镜走 `generate_storyboard`（整表 rows）+ `read_skill("storyboard-director")` 的自查规则；不要手写整表 rows、不要为每个镜头铺独立 storyboard 卡。
- 资产参考图考据归 `asset-aware-generation` / `research_asset_references`；本手册不管出图与画风。
- 不做的：不建审稿角色、不自动审稿、不生成诊断报告、不建第二套创作真相（正式事实以卡上正文为准）。
